# Market Trends & Performance Dashboard

Interactive business intelligence dashboard analysing sales trends, market performance, customer behaviour, and category growth using Power BI and DAX.

## Project Overview

This project analyses:
- Revenue trends
- Product category performance
- Customer purchasing behaviour
- Monthly sales growth
- Market performance indicators

## Tools Used

- Power BI
- DAX
- SQL
- Excel / CSV
- Data modelling
- Data visualisation
